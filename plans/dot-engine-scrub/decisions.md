# Architecture Decisions (pre-made, locked)

## D1 — Context-sensitive replacement, two rules

Import/package contexts (`'graphviz-ts/api'`, `'graphviz-ts/render'`, npm
mentions, `describe('graphviz-ts/api entry')`) → `@knowvah/dot-engine/...`.
Prose/branding → `dot-engine`. Rule order matters: specifier rule
(`graphviz-ts/` → `@knowvah/dot-engine/`) runs BEFORE the bare-name rule.
Case variant `graphviz-TS` (2 occurrences, plans/future/) folds into the
bare-name rule case-insensitively — but do NOT blanket-lowercase: only the
exact variants `graphviz-ts` and `graphviz-TS` are matched.

## D2 — Protected patterns (load-bearing paths, NEVER rewritten)

- `git/graphviz-ts` (filesystem paths to the repo dir, which keeps its name)
- `plans/graphviz-ts-port` (on-disk mission directory, keeps its name —
  user-confirmed; renaming would break @see pointers and journal refs)

Mechanism: sentinel-swap before replacement, restore after (see
diagrams/data-flow.md). A line containing both a protected path and a
branding mention gets only the branding mention rewritten.

## D3 — Golden SVG refs: patch the banner line only

`src/render/svg-graph.ts:37` already emits
`<!-- Generated by @knowvah/dot-engine -->`; the 7 refs-port SVGs are stale
on a line the golden comparator ignores (pack-components.test.ts:35). Patch
that one line per file; do NOT regenerate the refs.

## D4 — One deterministic script, not parallel hand-edits

`plans/dot-engine-scrub/tools/scrub.mjs`: takes explicit path-set arguments
(so T2/T3 stay inside their write-sets), supports `--dry-run` (report only,
zero writes). Excluded always: `.git`, `node_modules`, `dist`,
`.agent-notes/`, `.plan-mission-progress.md`, `plans/dot-engine-scrub/`
(self — the brief legitimately mentions the old name).

## D5 — One fresh corpus sweep at mission end

src/ edits are comment-only, but repo discipline sweeps before commit when
src/ is touched. Run once in T4. tsx is a local devDependency now; plain
`npm run survey` works in non-interactive shells.

## D6 — Only the name changes, not the description

"A faithful TypeScript port of Graphviz" phrasing stays everywhere — it is
factual and license-relevant. The scrub replaces the NAME `graphviz-ts` only.

## D7 — Out-of-scope trees

`.agent-notes/` (2 refs — path-keyed session state) and
`.plan-mission-progress.md` (deleted at handoff) are not scrubbed. The
`~/git/graphviz-ts` directory and GitHub repo name are out of scope by
prior user decision.

## Operational decisions

- Rollback: Reversible — revert the single squash commit on main; docs-typed
  PR cuts no release.
- Expected post-scrub remainder: pinned by T1's dry run (protected-pattern
  lines only, outside excluded trees). T4 verifies the identity exactly.
