# T1: seed `cluster` from the snapshot, tests, gates, squash

## Context

When a subgraph opens, cgraph copies into it every graph attribute in effect in
its parent (`agmakeattrs`, `lib/cgraph/attr.c:165`). So C's `is_a_cluster`
sees an inherited `cluster=true` through `agget`. The port snapshots those
values (`graphDefaultsSnapshot`, `src/parser/builder.ts:311`), but it seeds
only six label keys into `attrs`, and all three cluster tests read `attrs`.
T1 adds `cluster` to the seed list (AD-1).
[../harness/prototype.diff](../harness/prototype.diff) is the working
prototype: it meets every check below except the new tests and the rename.

## Interface contracts

There is no new interface. After `parse`, a subgraph whose snapshot holds
`cluster` and whose own body sets none has `attrs.get('cluster')` equal to the
snapshot's value, and `seededAttrs.has('cluster')`. Readers that depend on
this: `isACluster` (`dot/rank.ts`), `isCluster` (`osage/index.ts`,
`patchwork/index.ts`), `projectOne` (`dot/pack-components.ts`, by copying
`attrs`), and `-Tdot`'s `write_dict` skip (`render/dot/attrs.ts`, by
`seededAttrs`).

## Acceptance criteria

- Given `graph G { cluster=true; subgraph p { subgraph q { a } } subgraph r {
  subgraph q { b } } }`, when it renders under dot as svg, then it has 4
  `class="cluster"` groups (base: 0), and its xdot is byte-equal to native
  16.1.1.
- Given `r2.gv` (`cluster=true` on `p` and on `r`), when it renders under dot,
  then it has 4 clusters (base: 2), and its svg/xdot equal native apart from
  the svg header lines.
- Given `r1.gv`, when it renders under fdp, then stderr is native's
  `Warning: Two clusters named q - the second will be ignored`.
- Given `pack.gv` under dot, when it renders as `-Tdot`, then it is
  byte-equal to native. That is the reason for seeding over a snapshot read.
- Given gates 1-6, when they run on the head, then each passes as the README
  table says. The finished log has exactly one commit after the base, with
  footer `Refs: #183`, and tag `issue-183/pre-squash` holds the per-task
  history.
