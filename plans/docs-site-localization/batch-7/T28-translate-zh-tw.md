## Locale notes

CJK: no spaces are inserted around inline `code` beyond what reads
naturally; keep half-width punctuation inside code and links. Heading anchors
for CJK headings are generated by VitePress — link to them by the generated
slug, verified in the built HTML, not by guessing.

Use Taiwan terminology (e.g. 程式, 檔案, 預設), not Simplified-to-Traditional
conversion of the zh-cn pages. Translate from English.
