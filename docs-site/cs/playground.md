# Hřiště

Upravte DOT vlevo a SVG se aktualizuje živě. Vše běží ve vašem prohlížeči —
žádný server neexistuje. Moduly přepínáte v rozbalovací nabídce a tlačítky
**Exportovat SVG** / **Exportovat PNG** stáhnete aktuální vykreslení.

::: tip
Toto je skutečná knihovna, importovaná přímo ze zdrojového kódu. To, co tu
vidíte, je přesně to, co `renderSvg(dot, engine)` vytvoří ve vaší vlastní
aplikaci.
:::
