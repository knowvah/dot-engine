# Mänguväljak

Muutke vasakul DOT-i ja SVG uueneb reaalajas. Kõik töötab teie brauseris —
serverit ei ole. Vahetage paigutusmootoreid rippmenüüst ja kasutage nuppe
**Ekspordi SVG** / **Ekspordi PNG**, et praegune renderdus alla laadida.

<Playground height="600px" />

::: tip
See on päris teek, imporditud otse lähtekoodist. Siin nähtu on täpselt see,
mida `renderSvg(dot, engine)` toodab teie enda rakenduses.
:::
