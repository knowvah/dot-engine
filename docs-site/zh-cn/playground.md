# 演练场

编辑左侧的 DOT，右侧的 SVG 会实时更新。一切都在您的浏览器中运行——没有服务器。
通过下拉菜单切换布局引擎，并使用 **导出 SVG** / **导出 PNG** 下载当前的渲染结果。
