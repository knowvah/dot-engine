# Legeplads

Redigér DOT til venstre, og SVG'en opdateres live. Alt kører i din browser —
der er ingen server. Skift motor med rullemenuen, og brug
**Eksportér SVG** / **Eksportér PNG** til at downloade det aktuelle render.

<Playground height="600px" />

::: tip
Dette er det rigtige bibliotek, importeret direkte fra kildekoden. Det, du ser
her, er præcis det, `renderSvg(dot, engine)` producerer i din egen app.
:::
