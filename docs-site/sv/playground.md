# Lekplats

Redigera DOT-koden till vänster så uppdateras SVG:n direkt. Allt körs i din
webbläsare — det finns ingen server. Byt layoutmotor med rullgardinsmenyn och
använd **Exportera SVG** / **Exportera PNG** för att ladda ner den aktuella
renderingen.

<Playground height="600px" />

::: tip
Det här är det riktiga biblioteket, importerat direkt från källkoden. Det du ser
här är exakt vad `renderSvg(dot, engine)` producerar i din egen app.
:::
