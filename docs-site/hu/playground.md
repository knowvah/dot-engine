# Játszótér

Szerkessze a bal oldali DOT-ot, és az SVG élőben frissül. Minden a
böngészőjében fut — nincs szerver. Az elrendezésmotort a legördülő listával
válthatja, az **SVG exportálása** / **PNG exportálása** gombbal pedig
letöltheti az aktuális renderelést.

<Playground height="600px" />

::: tip
Ez a valódi könyvtár, közvetlenül a forrásból importálva. Amit itt lát, pontosan
az, amit a `renderSvg(dot, engine)` az Ön saját alkalmazásában előállít.
:::
