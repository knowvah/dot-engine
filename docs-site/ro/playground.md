# Zonă de testare

Editați DOT-ul din stânga, iar SVG-ul se actualizează live. Totul rulează în
browserul dumneavoastră — nu există server. Schimbați motoarele din lista
derulantă și folosiți **Exportați SVG** / **Exportați PNG** pentru a descărca
randarea curentă.

<Playground height="600px" />

::: tip
Aceasta este biblioteca reală, importată din codul sursă. Ceea ce vedeți aici
este exact ceea ce produce `renderSvg(dot, engine)` în propria dumneavoastră
aplicație.
:::
