# 레이아웃 엔진

Graphviz의 여덟 가지 레이아웃 엔진이 모두 등록되어 있습니다. 레이아웃 엔진 이름을
`renderSvg`의 두 번째 인자로 전달하세요:

```ts
renderSvg(dot, 'neato');
```

| 레이아웃 엔진 | 레이아웃 방식                                  |
|--------------|-----------------------------------------------|
| `dot`        | 계층형 / 레이어형 방향 그래프                    |
| `neato`      | 스프링 모델(Kamada–Kawai)                      |
| `fdp`        | 힘 기반                                        |
| `sfdp`       | 다중 스케일 힘 기반(대형 그래프)                 |
| `circo`      | 원형                                           |
| `twopi`      | 방사형                                         |
| `osage`      | 클러스터형                                     |
| `patchwork`  | 스콰리파이드 트리맵                             |

## 충실도에 관한 참고 {#fidelity-note}

엔진은 두 가지 적합성 등급으로 나뉩니다(정확한 정의와 비교 코드는
[적합성](/ko/conformance)을 참조하세요):

- **결정적** — `dot`, `circo`, `twopi`, `osage`, `patchwork`. 모두 같은
  **±0.01** 기준을 충족해야 합니다. 숫자 좌표와 경로는 골든 코퍼스에서 네이티브
  C 바이너리와 ±0.01pt 이내로 일치하며, 숫자가 아닌 모든 내용(태그, 색상, 텍스트)은
  완전히 같습니다.
- **반복적** — `neato`, `fdp`, `sfdp`. 부동소수점 반올림 순서에 좌우되는
  힘 기반/다중 스케일 솔버이므로, 엄격한 수치 일치 대신 더 느슨한 **±0.5**pt
  범위와 구조적 일치(같은 요소 트리)로 검사합니다.

두 기준 모두 SVG 출력이 바이트 단위로 같다는 주장은 아닙니다. 현재 통과 수와 엔진별로
허용된 차이는 [패리티](/parity)(엔진별 상세 페이지 포함)와
[알려진 차이](/ko/divergences)를 참조하세요.
