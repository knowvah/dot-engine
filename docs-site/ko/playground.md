# 플레이그라운드

왼쪽의 DOT를 편집하면 SVG가 실시간으로 갱신됩니다. 모든 것이 브라우저에서
실행되며 서버는 없습니다. 드롭다운으로 엔진을 전환하고, **SVG 내보내기** /
**PNG 내보내기**로 현재 렌더링 결과를 내려받을 수 있습니다.

<Playground height="600px" />

::: tip
이것은 소스에서 직접 가져온 실제 라이브러리입니다. 여기에서 보이는 결과는
여러분의 앱에서 `renderSvg(dot, engine)`가 생성하는 결과와 정확히 같습니다.
:::
