# Área de testes

Edite o DOT à esquerda e o SVG é atualizado ao vivo. Tudo roda no seu
navegador — não há servidor. Troque de mecanismo pela lista suspensa e use
**Exportar SVG** / **Exportar PNG** para baixar a renderização atual.

::: tip
Esta é a biblioteca de verdade, importada diretamente do código-fonte. O que
você vê aqui é exatamente o que `renderSvg(dot, engine)` produz no seu próprio
aplicativo.
:::
