# Zona de pruebas

Edita el DOT de la izquierda y el SVG se actualiza en vivo. Todo se ejecuta en
tu navegador — no hay ningún servidor. Cambia de motor con el desplegable y usa
**Exportar SVG** / **Exportar PNG** para descargar el renderizado actual.
