# Sandkassi

Breyttu DOT-kóðanum til vinstri og SVG-myndin uppfærist jafnóðum. Allt keyrir í
vafranum þínum — enginn þjónn kemur við sögu. Skiptu um vél með fellilistanum og
notaðu **Flytja út SVG** / **Flytja út PNG** til að sækja núverandi teikningu.

<Playground height="600px" />

::: tip
Þetta er raunverulega safnið, flutt inn beint úr frumkóða. Það sem þú sérð hér er
nákvæmlega það sem `renderSvg(dot, engine)` skilar í þínu eigin forriti.
:::
