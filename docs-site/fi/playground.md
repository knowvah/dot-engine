# Leikkikenttä

Muokkaa DOT-koodia vasemmalla, niin SVG päivittyy reaaliajassa. Kaikki toimii
selaimessasi — palvelinta ei ole. Vaihda asettelumoottoria alasvetovalikosta ja
lataa nykyinen renderöinti painikkeilla **Vie SVG** / **Vie PNG**.

<Playground height="600px" />

::: tip
Tämä on varsinainen kirjasto, tuotuna suoraan lähdekoodista. Se, mitä näet
tässä, on täsmälleen sama, minkä `renderSvg(dot, engine)` tuottaa omassa
sovelluksessasi.
:::
