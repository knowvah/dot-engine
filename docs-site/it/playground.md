# Area di prova

Modifica il DOT a sinistra e l'SVG si aggiorna dal vivo. Tutto gira nel tuo
browser — non c'è alcun server. Cambia motore con il menu a discesa e usa
**Esporta SVG** / **Esporta PNG** per scaricare il rendering corrente.

<Playground height="600px" />

::: tip
Questa è la vera libreria, importata direttamente dal codice sorgente. Ciò che
vedi qui è esattamente ciò che `renderSvg(dot, engine)` produce nella tua
applicazione.
:::
