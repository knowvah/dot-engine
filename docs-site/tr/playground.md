# Deneme Alanı

Soldaki DOT kaynak kodunu düzenleyin, SVG canlı olarak güncellenir. Her şey
tarayıcınızda çalışır — sunucu yoktur. Açılır menüyle motoru değiştirin ve
geçerli işlemeyi indirmek için
**SVG olarak dışa aktar** / **PNG olarak dışa aktar** düğmelerini kullanın.

<Playground height="600px" />

::: tip
Bu, kaynaktan içe aktarılan gerçek kitaplıktır. Burada gördüğünüz şey, kendi
uygulamanızda `renderSvg(dot, engine)` çağrısının ürettiğiyle birebir aynıdır.
:::
