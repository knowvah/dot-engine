# Механизмы компоновки

Зарегистрированы все восемь механизмов компоновки Graphviz. Передайте имя механизма
вторым аргументом в `renderSvg`:

```ts
renderSvg(dot, 'neato');
```

| Механизм     | Стиль компоновки                              |
|--------------|-----------------------------------------------|
| `dot`        | Иерархическая / послойная для ориентированных графов |
| `neato`      | Пружинная модель (Камада — Кавай)             |
| `fdp`        | Силовая                                       |
| `sfdp`       | Многомасштабная силовая (большие графы)       |
| `circo`      | Круговая                                      |
| `twopi`      | Радиальная                                    |
| `osage`      | Кластерная                                    |
| `patchwork`  | Квадратная древовидная карта (squarified treemap) |

## Примечание о точности

Механизмы делятся на два класса соответствия (точное определение и код сравнения
см. в разделе [Соответствие](/ru/conformance)):

- **Детерминированные** — `dot`, `circo`, `twopi`, `osage`, `patchwork`. К ним
  предъявляется одна и та же планка **±0,01**: числовые координаты и пути совпадают с
  нативным бинарником на C с точностью ±0,01pt, а все нечисловые данные (теги, цвета,
  текст) в точности равны на корпусе golden-тестов.
- **Итеративные** — `neato`, `fdp`, `sfdp`. Силовые/многомасштабные решатели, которые
  зависят от порядка округления чисел с плавающей запятой, поэтому проверяются по более
  мягкой границе **±0,5**pt и на структурное совпадение (то же дерево элементов), а не
  на жёсткое числовое равенство.

Ни одна из планок не утверждает побайтового совпадения вывода SVG. Актуальное число
пройденных тестов и принятые расхождения по каждому механизму смотрите в разделе
[Паритет](/parity) (со страницами подробностей по каждому механизму) и в разделе
[Известные расхождения](/ru/divergences).
