# Песочница

Редактируйте DOT слева — SVG обновляется на лету. Всё выполняется в вашем
браузере, сервера нет. Переключайте механизмы в выпадающем списке «Механизм компоновки»
и используйте **Экспорт SVG** / **Экспорт PNG**, чтобы скачать текущий результат
рендеринга.

<Playground height="600px" />

::: tip
Это настоящая библиотека, импортированная из исходного кода. То, что вы видите
здесь, в точности совпадает с тем, что `renderSvg(dot, engine)` выдаёт в вашем
собственном приложении.
:::
