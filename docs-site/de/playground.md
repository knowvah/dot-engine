# Spielwiese

Bearbeiten Sie das DOT auf der linken Seite, und das SVG aktualisiert sich live.
Alles läuft in Ihrem Browser — es gibt keinen Server. Wechseln Sie die Engines
über das Dropdown und laden Sie mit **SVG exportieren** / **PNG exportieren**
das aktuelle Rendering herunter.

<Playground height="600px" />

::: tip
Dies ist die echte Bibliothek, direkt aus dem Quelltext importiert. Was Sie hier
sehen, ist exakt das, was `renderSvg(dot, engine)` in Ihrer eigenen Anwendung
erzeugt.
:::
