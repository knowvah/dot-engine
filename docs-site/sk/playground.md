# Ihrisko

Upravujte DOT vľavo a SVG sa aktualizuje naživo. Všetko beží vo vašom
prehliadači — žiadny server neexistuje. Moduly prepínate v rozbaľovacom zozname
(**Modul rozloženia**) a pomocou **Exportovať SVG** / **Exportovať PNG** si
stiahnete aktuálne vykreslenie.

<Playground height="600px" />

::: tip
Toto je skutočná knižnica importovaná priamo zo zdrojového kódu. To, čo tu
vidíte, je presne to, čo `renderSvg(dot, engine)` vytvorí vo vašej vlastnej
aplikácii.
:::
