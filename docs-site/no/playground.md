# Lekeplass

Rediger DOT til venstre, så oppdateres SVG-en live. Alt kjører i nettleseren
din — det finnes ingen server. Bytt motor med nedtrekkslisten, og bruk
**Eksporter SVG** / **Eksporter PNG** for å laste ned den gjeldende renderingen.

<Playground height="600px" />

::: tip
Dette er det faktiske biblioteket, importert direkte fra kildekoden. Det du ser
her, er nøyaktig det `renderSvg(dot, engine)` produserer i din egen app.
:::
