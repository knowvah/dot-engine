# Speeltuin

Bewerk de DOT links en de SVG wordt live bijgewerkt. Alles draait in uw
browser — er is geen server. Wissel van engine via de keuzelijst en gebruik
**SVG exporteren** / **PNG exporteren** om de huidige weergave te downloaden.

<Playground height="600px" />

::: tip
Dit is de echte bibliotheek, rechtstreeks uit de broncode geïmporteerd. Wat u
hier ziet, is precies wat `renderSvg(dot, engine)` in uw eigen toepassing
produceert.
:::
