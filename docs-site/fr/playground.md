# Bac à sable

Modifiez le DOT à gauche et le SVG se met à jour en direct. Tout s’exécute
dans votre navigateur — il n’y a pas de serveur. Changez de moteur avec la
liste déroulante, et utilisez **Exporter en SVG** / **Exporter en PNG** pour
télécharger le rendu actuel.

<Playground height="600px" />

::: tip
Il s’agit de la vraie bibliothèque, importée depuis les sources. Ce que vous
voyez ici est exactement ce que `renderSvg(dot, engine)` produit dans votre
propre application.
:::
