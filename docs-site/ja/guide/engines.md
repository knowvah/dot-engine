# レイアウトエンジン

Graphviz の 8 つのレイアウトエンジンはすべて登録されています。エンジン名を
`renderSvg` の第 2 引数として渡します。

```ts
renderSvg(dot, 'neato');
```

| エンジン       | レイアウトのスタイル                                  |
|--------------|-----------------------------------------------|
| `dot`        | 階層型 / 層状の有向グラフ        |
| `neato`      | バネモデル（Kamada–Kawai）                   |
| `fdp`        | 力指向                                |
| `sfdp`       | 多重スケールの力指向（大規模グラフ向け）      |
| `circo`      | 円形                                      |
| `twopi`      | 放射状                                       |
| `osage`      | クラスター型                                     |
| `patchwork`  | スクエア化されたツリーマップ                            |

## 忠実度に関する注記 {#fidelity-note}

エンジンは 2 つの適合クラスに分かれます（正確な定義と比較コードは
[適合性](/ja/conformance)を参照してください）。

- **決定論的** — `dot`、`circo`、`twopi`、`osage`、`patchwork`。いずれも同じ
  **±0.01** の基準が課されます。ゴールデンコーパスにおいて、数値の座標とパスはネイティブの
  C バイナリと ±0.01pt 以内で一致し、数値以外の内容（タグ、色、テキスト）は
  完全に一致します。
- **反復的** — `neato`、`fdp`、`sfdp`。浮動小数点の丸め順序に依存する、
  力指向/多重スケールのソルバーです。そのため、厳密な数値の一致ではなく、
  より緩い **±0.5**pt の範囲と、構造上の一致（同じ要素ツリー）で検証されます。

どちらの基準も、SVG 出力がバイト単位で完全に一致するという主張ではありません。現在の合格数と
エンジンごとの受け入れ済みの差異については、[パリティ](/parity)（エンジン別の詳細ページあり）と
[既知の差異](/ja/divergences)を参照してください。
