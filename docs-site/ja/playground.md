# プレイグラウンド

左側の DOT を編集すると、SVG がライブで更新されます。すべてがブラウザー内で動作し、
サーバーは使いません。ドロップダウンでエンジンを切り替え、
**SVG をエクスポート** / **PNG をエクスポート** で現在のレンダリング結果をダウンロードできます。

<Playground height="600px" />

::: tip
これはソースから直接インポートした実際のライブラリです。ここに表示されるのは、
お使いのアプリで `renderSvg(dot, engine)` が生成するものと全く同じです。
:::
