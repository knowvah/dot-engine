# post-16-1-followups-11 mission — observations (2026-11-09)

## Observation: native fdp first layouts vary with heap addresses too
- **Context**: T4 (`graphs-fdp` json) and T7 (`tests/graphs/fdp.gv` xdot).
- **Finding**: the pointer comparisons at `lib/fdpgen/layout.c:466,501,637` act on a first layout as well,
  not only after a free (part 10's note). `fdp.gv` xdot gives 2 classes over 16 stock runs (14/2) and
  16/16 under part 10's `noaddr.patch` with `GVTS_NOADDR=1`; `graphs-fdp` json gives 2 classes over 16.
  The port equals the settled (majority) class.
- **Impact**: a single native run is not a reference for fdp on graphs with clusters or cluster edges;
  run it 16 times, or use the noaddr build, before reading a miss as a port bug.
- **Confidence**: High for the ids measured.

## Observation: native dot no-free relayouts read freed memory but still repeat
- **Context**: T8, `graphs/nestedclust.gv`, three layouts with no free (part 10 `twice.c nofree`).
- **Finding**: walking `GD_nlist` of a cluster after layout 2's mincross segfaulted an instrumented
  native; renders 2 and 3 are degenerate (most nodes at x=0, stale bb) yet repeat 8 of 8. Zeroing
  decompose's `Cmark` per layout (the port's old model) makes native segfault in layout 3.
- **Impact**: on no-free relayouts, process statics that count across layouts (`Cmark`) are part of the
  spec; a per-layout reset in the port is not a native state. Only `Cmark` was audited (follow-up 152).
- **Confidence**: High

## Observation: Spline.bb was never computed, which explains edge_in_box's old regression
- **Context**: T7/T7b, subgraph renders on fdp and osage.
- **Finding**: C fills `spl->bb` in `init_splines_bb` (`emit.c:4101-4163`) before every render and
  `edge_in_box` tests it (`emit.c:2692`). The port left `Spline.bb` at `{0,0,0,0}`, so restoring the
  test had dropped neato and circo edges; with `init_bb`/`arrow_bb` ported (`src/common/emit-bb.ts`)
  the test is back and no smoke id loses an edge.
- **Impact**: a C test that "regresses" when ported usually means its input is missing, not that the
  test is wrong; check what fills the field.
- **Confidence**: High

## Observation: macOS printf prints nan without a sign
- **Context**: T7b (C), xdot `bb` and draw ops for an infinite bounding box.
- **Finding**: C's `%f`/`%g` print `inf`, `-inf` and `nan`; macOS libc prints `nan` even for a
  negative NaN (glibc prints `-nan`). The port's `printfNonFinite` (`src/util/printf-round.ts`)
  follows macOS, the oracle platform.
- **Impact**: a Linux native run differs from the oracle on `-nan`; not a port bug.
- **Confidence**: High (macOS measured; glibc from its documented behaviour)

## Observation: V8 Math.hypot misses macOS libm on 37% of sgd calls
- **Context**: T6, `sgd58` (neato `mode=sgd`, 58 nodes).
- **Finding**: `Math.hypot` differs in the last bit from macOS `hypot` on 18516 of 49590 calls at
  `sgd.c:223`, and `Math.exp` on 4 of 30 eta values (`sgd.c:216`). With `src/common/libm-hypot.ts`
  and macOS `exp` replayed, the 54731-line trace and `-Tdot` equal native. Closed under PR 119.
- **Impact**: sgd amplifies a 1-ulp miss to 1.59 points; treat any sgd delta as libm first.
- **Confidence**: High

## Observation: bytediff.ts runs applicable ids only
- **Context**: T12, the 21 quarantined ids.
- **Finding**: `test/tools/bytediff.ts` filters the manifest to `status === 'applicable'`, so an ids file
  of quarantined ids throws `unknown id`. A scratch copy of `test/corpus/corpus-manifest.json` with
  their status flipped, passed through `BD_REPO=<dir>`, runs them (the manifest is all it reads there).
- **Impact**: use that for every close-out's quarantined bytediff.
- **Confidence**: High

## Observation: the 16.1.1 oracle needs Homebrew bison and flex
- **Context**: building `oracle/16.1.1` (`~/git/graphviz-16.1.1`, issue #146) during T12.
- **Finding**: a plain `cmake -S . -B build` fails configure with `BISON (required version >= 3.0)` missing:
  macOS ships bison 2.3. The 16.1.0 cache pins `BISON_EXECUTABLE=/opt/homebrew/opt/bison/bin/bison` and
  `FLEX_EXECUTABLE=/opt/homebrew/opt/flex/bin/flex`; pass both. The plugins become `8.0.16`, so scripts
  that rewrite `8.0.15` link lines (`harness/T7/build.sh`) need the version as a parameter.
- **Impact**: every fresh oracle build on this machine needs the two flags.
- **Confidence**: High

## Observation: comparing bytediff output with native needs three normalizations
- **Context**: T12, classifying the full bytediff's 2,282 diffs against native 16.1.0.
- **Finding**: (1) svg: the port prints `<!-- Generated by @knowvah/dot-engine -->` and breaks the
  `<svg>` tag over two lines; native prints its version banner and one line. Strip everything through
  the first line containing `xmlns=` before comparing. (2) json: native prints bare `nan`/`inf`/`-inf`
  in arrays (`[[inf,inf],[inf,nan]]`), which `JSON.parse` rejects; quote only tokens outside strings
  (a `bb` string `"inf,inf,nan,nan"` must stay as it is). (3) `1367` holds a non-UTF-8 byte in a node
  name: use `LC_ALL=C` for awk/sed/diff and read files as latin1, or awk stops at that line. Wrap-only
  checks: drop `\` + newline from both sides.
- **Impact**: without these, every svg diff looks like a mismatch with native and the json tools crash.
- **Confidence**: High

## Observation: the port renders only the first graph of a multi-graph file
- **Context**: T12, quarantined id `2835` (two graphs in one file).
- **Finding**: native `-Kneato -Txdot` prints both graphs; the port prints the first. Up to the end
  of the first graph the head output equals native.
- **Impact**: compare only the first graph on multi-graph quarantined ids.
- **Confidence**: High
